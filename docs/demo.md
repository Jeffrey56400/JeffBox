# JeffBox 笔记示例

一个**单文件 exe** 的轻量工具箱：待办 · 笔记 · 启动器。这篇文档演示 Markdown 渲染能力。

## 常用语法

- 行内样式：**加粗**、*斜体*、`行内代码`、~~删除线~~、==高亮==
- 大文件流式渲染：首屏 300 块，滚动到底自动续载
- 支持脚注[^1]与数学公式 $E = mc^2$

## 表格

| 工具 | 定位 | 特色 |
| --- | --- | --- |
| 待办 | 任务树 | 子任务无限嵌套 / 提醒 |
| 笔记 | Typora 式 | 编辑⇄预览同屏切换 |
| 启动器 | 磁贴墙 | 拖入即加 / 按频次排序 |

## 代码块

```csharp
// 零外部依赖，.NET 9 + WPF 原生开发
var box = new JeffBox();
box.Run(); // 450KB，双击即用
```

> 超大文件（3.5MB+）秒开：惰性迭代器按块渲染，内存占用稳定。
